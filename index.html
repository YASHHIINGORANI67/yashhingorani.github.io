06 / Model Explorer

Research methodology explorer

Expand each concept for a concise explanation of its application.

Value at Risk (VaR)

A model-based loss threshold for a specified horizon and confidence level. A 99% one-day VaR corresponds to a 1% modelled probability of exceeding that threshold.

Expected Shortfall (ES)

Measures the average loss in the tail beyond a specified VaR threshold, under the relevant estimation assumptions.

Probability of Default (PD)

Estimates the probability that a borrower defaults over a specified time horizon, conditional on available information and model assumptions.

Logistic Regression

Models the probability of a binary outcome, such as borrower default, using explanatory variables.

ARMA / GARCH

ARMA models linear time-series dependence; GARCH describes changing conditional variance and volatility clustering.

Extreme Value Theory (EVT)

Statistical methods for modelling extreme observations, including peaks-over-threshold and Generalized Pareto tail models.

Monte Carlo Simulation

Generates repeated simulated outcomes under a specified model to estimate distributions, loss thresholds and risk statistics.

Ordinary Least Squares (OLS)

Estimates linear regression coefficients by minimizing squared residuals. Diagnostic tests help evaluate model assumptions.

Maximum Drawdown

The largest observed percentage decline from a previous peak to a subsequent trough in an asset or portfolio series.

Sharpe / Sortino Ratios

Risk-adjusted return metrics. Sharpe uses total return variability, while Sortino focuses on downside deviation.

MACD

A momentum indicator based on differences between exponential moving averages, sometimes evaluated in rule-based trading strategies.

Regression Diagnostics

Tools such as Ramsey RESET, Breusch–Pagan and Jarque–Bera investigate specification, heteroskedasticity and residual normality.
